# 💻 Scripts y comandos

Esta carpeta contendrá scripts y comandos de PowerShell utilizados durante el laboratorio.

Cada script deberá incluir:

- Objetivo
- Requisitos
- Comandos utilizados
- Resultado esperado
- Notas de seguridad

> Nunca se deben guardar contraseñas, tokens ni credenciales reales dentro de los scripts.
